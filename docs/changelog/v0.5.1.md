# v0.5.1 (2026-08-31)

## Bug Fixes

- 巨大数値列（`parseFloat`が`Infinity`を返す）のorderセグメントがフォーマット検証を通過し、重複解消処理が無限ループ（ハング）する問題を修正（`Number.isFinite`検証を追加）(#38)
- `Number.MAX_VALUE`セグメント（有限だが後続値生成が`Infinity`になる）による重複解消の無限ループを防止（同値を拒否し、割り当てループで有限値枯渇時に断念して元の値を保持）(#38)

## Internal Improvements

- テストが非git環境のcwdとして/tmp直下の架空パスを利用し、`/tmp/.git`が存在する環境で失敗する問題を修正（home直下sandbox方式に変更し、環境汚染に非依存化）
