# v0.5.0 (2026-07-18)

## New Features

- 新status `blocked`（外部条件待ちの強制ブロック）を追加。開始条件 `gate`（自由テキスト、blocked化時は必須）を保持
- `tm block <id> --gate "..."` / `tm unblock <id> [--status wip]` コマンドを追加
- `tm update` に `--gate` / `--force` オプションを追加。blocked からの遷移は CLI が技術的に拒否し、`tm unblock` または `--force`（ユーザー確認後）のみ解除可能
- `tm finish` は blocked タスクを拒否、`tm close` は許可（キャンセル扱い）
- `tm list` で blocked をデフォルト・`--open` から除外（`-a` / `-s blocked` で表示、`[BLOCKED: <gate>]` を表示）
- `--global` フラグと `CODING_AGENT_ROOT` 環境変数を追加: git管理外でも `~/.task-memory.json`（ホーム）を保存先として明示的に使用可能に (#27)
- タスクの作成/更新/クローズ/完了/リリース時にコミットハッシュ（`created_commit` / `updated_commit`）を記録するように (#28)

## Changes

- 非git環境でのホームディレクトリへの暗黙フォールバックを削除: git管理下、または `--global` / `CODING_AGENT_ROOT` の明示指定が必要に (#27)

## Bug Fixes

- `tm update --status blocked` で `--gate` の値が未指定（または別オプション）の場合、pre-scanをすり抜けて `gate` 未設定のまま blocked 化されてしまう問題を修正（`--gate` の存在ではなく有効な値を検証するよう厳密化）(#31)
- `tm block` / `tm unblock` で `-x` 等の単一ハイフン未知オプションがタスクIDとして誤って解釈される問題を修正（`-` で始まる未知トークンをエラーにするよう統一）(#31)
- `tm finish` で既に done のタスクに `--body` を指定すると本文が破棄されるバグを修正 (#29/#30)
- `getCurrentCommit()` の git worktree 対応とエッジケースの堅牢化（try-catch追加、4コマンドで commit hash をクリア） (#28)
- `uncaughtException` の rethrow による無限再帰リスクを修正し、try-catch ベースのエラーハンドリングに移行 (#27, #29/#30)

## Internal Improvements

- `_bodies_note` メッセージを英語化、`body` / `bodies` の単数形・複数形を正しく使い分け (#25/#26)
- 各コマンドの不足していたヘルプ/ドキュメントを補完 (#28)
- `reviewStore.ts` の重複 import を統合 (#27)
- `--global` フラグのパースを行頭のみに制限し、誤認識を防止 (#29/#30)
