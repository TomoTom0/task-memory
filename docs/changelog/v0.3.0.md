# v0.3.0 (2026-03-22)

## New Features

- **sync: 暗号化設定の分離** (`TASK-8`): 暗号化鍵の設定を `tm sync add` から分離し、`tm sync set key` / `tm sync set encrypt` で独立して管理できるようになりました。identity（秘密鍵）と recipient（公開鍵）を分離した非対称暗号化設計により、push 側は公開鍵で暗号化し、pull 側は秘密鍵で復号します。グローバル設定（`--global`）で全プロジェクトへのデフォルト適用も可能です。
- **sync: save/load コマンド追加**: `tm sync push/pull` を実態に合わせて `tm sync save/load` にリネームしました。
- **sync: upload コマンド追加**: `tm sync save` + `git commit` + `git push` を一括実行する `tm sync upload` コマンドを追加しました。デフォルトのコミットメッセージは `sync: YYYY-MM-DD HH:MM` です。
- **sync: repo サブコマンド追加**: `tm sync repo create/set/show` で GitHub リポジトリの作成・remote 設定・確認ができるようになりました（`gh` コマンド必要）。
- **docs コマンド追加**: `tm docs` でユーザーガイドをターミナルに表示できるようになりました。

## Bug Fixes

- **order: 重複 order の連番振り直し** (`TASK-5`): 同じ order 値が複数のタスクに割り当てられた場合、重複を許容せず連番に振り直すように修正しました。
- **order: 挿入セマンティクスの実装** (`TASK-5`): 既存の order と同じ値を新規タスクに設定した場合、新しいタスクが優先され、既存タスクが後ろにシフトされるようになりました（`updated_at` が新しい方が優先）。

## Internal Improvements

- **テスト基盤の改善** (`TASK-4`): テストがプロジェクト本体のタスクストアを上書きしてしまう問題を修正しました。`test/helpers/testProject.ts` を新設し、一時 git リポジトリを使ったサブプロセス方式に切り替えることで完全に分離しました。
- **sync: マージロジックの改善** (`TASK-5`): `id + created_at` の複合キーで同一タスクを判定するようになりました。ID のみの衝突は新しい ID を割り当てて取り込みます。
- **sync: age コマンド未インストール時のエラー改善** (`TASK-7`): `encryptData`・`decryptData`・`generateAgeKey` で `spawnSync` の `result.error` を確認するようにしました。`age`/`age-keygen` がインストールされていない場合に「コマンドが見つかりません」という明確なエラーメッセージを表示します。
