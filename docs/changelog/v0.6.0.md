# v0.6.0 (2026-09-10)

## New Features

- `tm sync clone <url>` サブコマンドを追加。既存のremote sync repoをCLIから直接cloneでき、別PCの初回セットアップから手動git cloneを排除 (#42)
- `tm sync add --remote <url>` / `tm sync set --remote <url>` でremote originの設定・変更が可能に。接続時にローカルが空repoならremoteの内容を自動adoptして復旧をCLI完結化 (#42)
- `tm sync push` / `pull` の状態事前検出（origin未設定・sync repo未初期化など）と次の一手を示すガイドを追加。`tm sync status` にremote URL行を表示 (#42)

## Changes

- `tm sync` の同期対象を `projects/` 配下のタスクデータのみに限定。`config.json`（`defaultAuto` 等の同期クライアント設定）と `.gitignore` はPC単位のローカル設定として同期対象外になった。旧版でremoteへcommit済みのこれらファイルは次回のpushで自動的にremoteから除外される（ローカルのファイルは削除されない） (#44)

## Bug Fixes

- 他PCの新版pushがremoteに入れた `projects/` 外ファイルの削除commitをpullしても、pull実行PCの旧版由来ローカル設定ファイル（`config.json` / `.gitignore` 等）が作業ツリーから消えないよう保護（欠損時は自動復元し `Restored local files excluded from sync:` を表示） (#44)
- 旧版の `git add .` や `tm git` 経由で追跡済みの `projects/` 外ファイル（`config.json` / `.gitignore` 以外を含む）も、push時にindexから外してremoteへcommitされないように修正 (#44)
- 環境変数 `CODING_AGENT_ROOT` にmonorepoのサブディレクトリを指定した場合でも、親方向へ `.git` を遡上してリポジトリルートを解決するように修正（相対パスは絶対化、実在しないパス指定で祖先の別リポジトリへ誤解決しないガード、symlink指定の実パス解決込み） (TASK-7, TASK-11)

## Internal Improvements

- テスト隔離をvitest setupFiles / globalSetupに集約し、実データ（repo側DB・`~/.local/task-memory` 等）への到達を構造的に防止。run前後の実データhash比較guardを導入 (#43)
- 親環境の `GIT_TEMPLATE_DIR`（実行可能hook含む）がテスト内のgit initでsandbox repoへコピーされる経路を遮断 (#43)
- 実データhash比較guardの監視対象にsymlinkの参照実体を含め、link越しの書き込みも検知できるようにhash化 (#43)
